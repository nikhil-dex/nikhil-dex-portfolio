## ✨ About

This is my personal portfolio website and a playground for experimenting with modern frontend interactions.

The site is designed around a minimal visual system with **3D elements, motion, glassmorphism, scroll-driven interactions, animated project cards, and custom navigation** rather than a conventional static portfolio layout.

It presents my:

- 👨‍💻 Development background
- 🚀 Selected projects
- 🧠 Technology stack
- 🛠️ Services and capabilities
- 📫 Contact and social profiles

---

## 🚀 Getting Started

### 1. Clone

```bash
git clone https://github.com/nikhil-dex/nikhil-dex-portfolio.git
cd nikhil-dex-portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

### 5. Preview production build

```bash
npm run preview
```

### 6. Lint

```bash
npm run lint
```

## 🎯 Design Philosophy

The portfolio is built around a simple idea:

> **A developer portfolio should feel like a product, not a résumé on a webpage.**

Instead of relying only on text and cards, the site uses motion, spatial composition, 3D elements and interaction to make the work itself part of the presentation.
